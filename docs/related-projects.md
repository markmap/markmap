Projects that use Markmap. Those not under the [markmap organization](https://github.com/markmap) are maintained by their own authors, and some may still be on the `markmap-*` packages, so they may not have every feature yet.

## Editors

- [VS Code](https://marketplace.visualstudio.com/items?itemName=gera2ld.markmap-vscode), also on [Open VSX](https://open-vsx.org/extension/gera2ld/markmap-vscode)
- Vim / Neovim: [coc-markmap](packages/coc-markmap.md), powered by [coc.nvim](https://github.com/neoclide/coc.nvim)
- Neovim: [markmap.nvim](https://github.com/Zeioth/markmap.nvim), without coc.nvim
- Emacs: [eaf-markmap](https://github.com/emacs-eaf/eaf-markmap), powered by [EAF](https://github.com/emacs-eaf/emacs-application-framework)

## AI tools

- [markmap-mcp-server](https://github.com/jinzcdev/markmap-mcp-server): an MCP server that turns Markdown into interactive maps
- [mindmap-skills](https://github.com/galiacheng/mindmap-skills): an agent skill that makes a map from a file, a URL or a topic

## Web apps

- [text2diagram](https://text2everything.vip): describe a map in plain language and get an interactive one in the browser

- be available now and maintained
- be marked as `paid` if it costs money to use
