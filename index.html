Rich labels

Bold, links, code, highlights, task lists, images and math, all drawn on the map.

Notes

Very large maps

Links that carry it all

Options in the document

Use it where you work

On a web page

One script turns each block into a map as it scrolls into view.

<script type="module"
  src="https://cdn.jsdelivr.net/npm/@markmap/autoloader@1/+esm">
</script>

<div class="markmap" data-theme="cards">
  <script type="text/markdown">
    # Trip
    ## Before
    ## During
  </script>
</div>
Autoloader

In an app

A web component that works with any framework.

import '@markmap/element';

<markmap-view
  src="./notes.md"
  theme="cards"
  layout="two-sided"
  toolbar
></markmap-view>
Web component

From the command line

One offline HTML file, or an image for scripts and CI.

markmap notes.md
markmap notes.md --svg
markmap notes.md --png
