markmap

What is markmap?

Markmap turns Markdown into an interactive mind map. Headings and list items become branches you can fold, zoom and pan. Other text, such as paragraphs and code, stays with its branch as a note.

The easiest way to try it is the 👉 editor. You can also use it in:

  • VS Code 🚀
  • the command line, with @markmap/cli
  • Vim / Neovim, with coc-markmap
  • many other tools

Learn the basics

  • Writing maps: what becomes a branch, a note, or part of a label
  • Themes and layouts: the looks and shapes a map can take
  • Options: settings you can keep in the document itself
  • Magic comments: fold chosen branches
