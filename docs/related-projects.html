Related projects

Projects that use Markmap. Those not under the markmap organization are maintained by their own authors, and some may still be on the markmap-* packages, so they may not have every feature yet.

Editors

  • VS Code, also on Open VSX
  • Vim / Neovim: coc-markmap, powered by coc.nvim
  • Neovim: markmap.nvim, without coc.nvim
  • Emacs: eaf-markmap, powered by EAF

AI tools

  • markmap-mcp-server: an MCP server that turns Markdown into interactive maps
  • mindmap-skills: an agent skill that makes a map from a file, a URL or a topic

Web apps

  • text2diagram: describe a map in plain language and get an interactive one in the browser
